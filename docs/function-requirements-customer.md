# Functional requirements for unregistered and registered users/customers: 

//How it works for a customer or user.

1. Access platform and discover events

   - the system must allow any user/customer to open the web application in any modern browsers like  "microsoft edge" without login to browse events.

2. search, filter and sort events on search bar

   - the system must allow user/customer to search and filter events to discover relevant events    quickly

3. view events details

   - when user/customer clicks or open an event card, the system must display full events details

4. Authentication to book ticket

   - the system shall require login/sign-up before ticket booking to secure purchase

5. book and purchase events ticket

   - all authenticated customer shall be able to book and purchase a ticket

6. generate and display digital ticket with QR code 

   - upon successful booking, the system shall  generate and display digital ticket in detail.

7. save and download ticket

   - the system shall allow customer to save tickets for offline use.

8. ticket and booking history

   - logged-in customer shall be able to view all purchase tickets in one place
